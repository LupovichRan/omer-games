# המשחקים של עומר

Simple offline-friendly Hebrew games for kids, on GitHub Pages at https://lupovichran.github.io/omer-games/.
Each game is one self-contained `index.html` (inline CSS/JS, no external assets) in its own folder.

- `/` – menu / launcher
- `/pikachu/` – Pikachu catches falling balls
- `/science/` – Pikachu science lab (sink or float, ramp, magnet)
- `/memory/` – Pikachu memory match (easy/medium/hard, moving-cards mode)

## Installable apps (PWA)
The menu **and every game** are separate installable apps (home-screen icon, works offline):

| file (per app folder) | what |
|---|---|
| `manifest.webmanifest` | own `id` / `scope` / `start_url` = the folder (`/omer-games/<game>/`, menu = `/omer-games/`), Hebrew, `rtl`, standalone |
| `icons/` | `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` (180) |
| `sw.js` | service worker, scope = the folder; cache-first, cache name `omer-<app>-<content hash>`; only deletes its own old caches. The menu's SW also precaches all games, so the launcher works fully offline |
| `pwa.js` | registers `sw.js`, puts a small **📲 התקן כאפליקציה** button into the element with `data-pwa-slot` (Android/Chrome → native prompt, iPhone → Hebrew "Share → Add to Home Screen" steps), hides it when running as an app, opens the install panel for `?install=1`, adds a 📲 badge to each menu tile |
| `index.html` | `<!-- PWA --> … <!-- /PWA -->` block in `<head>` (manifest, theme-color, apple tags, `pwa.js`) |

All of this is generated by **`tools/new-game-pwa.py`** (templates in `tools/templates/`). Don't edit `sw.js`/`pwa.js` in game folders by hand.

## Adding a game
1. Create a folder, e.g. `dino/`, with a single self-contained `index.html` (Hebrew, `dir="rtl"`, `lang="he"`).
   Put `<div data-pwa-slot></div>` on its start screen (under the play button) – the install button goes there.
   The 🏠 button may link to `../index.html` (the menu).
2. Run (needs Python 3 + Pillow; icons are drawn from the emoji):
   ```
   python3 tools/new-game-pwa.py dino --name "הדינוזאור של עומר" --short "דינו" --emoji 🦖 --colors "#aed581,#33691e"
   ```
   This writes the manifest, icons, `pwa.js`, `sw.js`, patches the `<head>`, adds a tile to the menu
   (`<a class="game cN" …>`, colors `c1`–`c4`) and regenerates every service worker (incl. the menu's).
3. Commit to `main`; GitHub Pages redeploys automatically in ~1 minute.

## After editing ANY game or the menu
Run `python3 tools/new-game-pwa.py --all` before committing – it refreshes the content-hash versions of the
service workers so installed apps pick up the update (they also refresh pages in the background).
To redraw a game's icons: add `--icons` (with `--emoji`/`--colors`).
