# המשחקים של עומר

Simple offline-friendly Hebrew games for kids, on GitHub Pages at https://lupovichran.github.io/omer-games/.
Each game is one self-contained `index.html` (inline CSS/JS, no external assets) in its own folder.

- `/` – menu / launcher
- `/pikachu/` – Pikachu catches falling balls
- `/science/` – Pikachu science lab (sink or float, ramp, magnet)
- `/memory/` – Pikachu memory match (easy/medium/hard, moving-cards mode)
- `/brain/` – Brain gym, `/gifted/` – gifted-test style thinking game
- `/shared/parental.js` – parental controls + daily time limit for all of the above

## Installable apps (PWA)
The menu **and every game** are separate installable apps (home-screen icon, works offline):

| file (per app folder) | what |
|---|---|
| `manifest.webmanifest` | own `id` / `scope` / `start_url` = the folder (`/omer-games/<game>/`, menu = `/omer-games/`), Hebrew, `rtl`, standalone |
| `icons/` | `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` (180) |
| `sw.js` | service worker, scope = the folder; cache-first, cache name `omer-<app>-<content hash>`; only deletes its own old caches. The menu's SW also precaches all games, so the launcher works fully offline |
| `pwa.js` | registers `sw.js`, puts a small **📲 התקן כאפליקציה** button into the element with `data-pwa-slot` (Android/Chrome → native prompt, iPhone → Hebrew "Share → Add to Home Screen" steps), hides it when running as an app, opens the install panel for `?install=1`, adds a 📲 badge to each menu tile |
| `index.html` | `<!-- PWA --> … <!-- /PWA -->` block in `<head>` (manifest, theme-color, apple tags, `pwa.js`) |

All of this is generated by **`tools/new-game-pwa.py`** (templates in `tools/templates/`). Don't edit `sw.js`/`pwa.js` in game folders by hand.

## Parental controls (`shared/parental.js`)
One shared script loaded by the menu and **every** game (same origin → one shared `localStorage`):
- **Daily total play time across all games**, default **55 min**, resets at local midnight (record per date: `omerPC_day_YYYY-MM-DD`).
  Counts only while a game page is visible and the child touched/typed in the last 3 min (menu time isn't counted).
  Multi-tab safe: only the tab holding a fresh heartbeat (`omerPC_hb`) counts.
- Kid badge **⏳ N′** bottom-left (green → yellow ≤15 → red ≤5, pulsing ≤1; tap = hear remaining time). Spoken + visual Pikachu warnings at 5 and 1 min left.
- Time up / "End play now" / outside allowed hours → full-screen sleeping-Pikachu lock (top z-index, game content made `inert`, input blocked, re-applied every second if removed). Only the parent PIN opens it.
- **Parents:** small 🔒 button bottom-right of the menu, the "🔒 Parents · הורים" button on the lock screen, or long-press the ⏳ badge 2 s in any game.
  First time: create a 4-digit PIN (stored as salted SHA-256 in `omerPC`). Panel: today's usage + per-game breakdown, +10/+15/+30 min,
  daily limit (on/off, minutes), optional allowed hours (off by default; bonus time also allows play outside them), end play now, reset today, change PIN.
  5 wrong PINs → 2 min lockout. Forgot PIN → clear the site's data in browser settings (also clears game progress).
- Client-side only: clearing browser data removes it. For hard enforcement use iOS Screen Time / Google Family Link.
- `tools/new-game-pwa.py` adds `<script src="../shared/parental.js" defer>` to every app's `<!-- PWA -->` block and precaches it in every
  service worker, so **new games get it automatically** – just run the tool. Tests: `omer-games-shots/parental-test.js <base-url>`.

## Adding a game
1. Create a folder, e.g. `dino/`, with a single self-contained `index.html` (Hebrew, `dir="rtl"`, `lang="he"`).
   Put `<div data-pwa-slot></div>` on its start screen (under the play button) – the install button goes there.
   The 🏠 button may link to `../index.html` (the menu).
2. Run (needs Python 3 + Pillow; icons are drawn from the emoji):
   ```
   python3 tools/new-game-pwa.py dino --name "הדינוזאור של עומר" --short "דינו" --emoji 🦖 --colors "#aed581,#33691e"
   ```
   This writes the manifest, icons, `pwa.js`, `sw.js`, patches the `<head>`, adds a tile to the menu
   (`<a class="game cN" …>`, colors `c1`–`c4`) and regenerates every service worker (incl. the menu's).
3. Check the game shows the ⏳ badge (parental controls) – `grep parental.js dino/index.html`.
4. Commit to `main`; GitHub Pages redeploys automatically in ~1 minute.

## After editing ANY game or the menu
Run `python3 tools/new-game-pwa.py --all` before committing – it refreshes the content-hash versions of the
service workers so installed apps pick up the update (they also refresh pages in the background).
To redraw a game's icons: add `--icons` (with `--emoji`/`--colors`).

## Adding a game to the store shelves (root menu)
The root `index.html` shows games on shelves (left / front / right). Edit the `SHELVES` array in its `<script>`:
add `{href:'folder/index.html', emoji:'🎲', name:'שם קצר', color:'#hex1,#hex2'}` to a shelf's `games`
(keep ≤4 per shelf; if full, add a new shelf object `{icon, title, games:[...]}`). Array order = visual left→right;
the middle shelf is shown first. Then bump `VERSION` in root `sw.js` (or run `tools/new-game-pwa.py --all`).
