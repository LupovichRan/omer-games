# Security Policy

## Reporting a vulnerability

This project is a static site. Each page is self-contained HTML with inline CSS and JavaScript. There is no server, account system, or application dependency manifest.

Report security issues privately through [GitHub Security Advisories](https://github.com/LupovichRan/omer-games/security/advisories/new). Do not open a public issue for a vulnerability.

Include a short description, how to reproduce it, and the impact. Please give the maintainers time to fix the issue before any public disclosure.
